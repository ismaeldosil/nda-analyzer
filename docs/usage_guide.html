NDA Analyzer

M&A NDA Analysis Prompt for LLMs

Usage Guide v2.7

Using with ChatGPT

Option 1: Direct in Conversation Recommended

Works with any prompt length. Interactive onboarding.

  1. Go to chatgpt.com
  2. Click New chat (top left corner)
  3. Copy the entire NDA Analyzer prompt and paste it into the message box
  4. Press Enter to send - the analyzer will ask for your preferences
  5. Reply with your choices or type "defaults" to use standard settings
  6. Click the paperclip icon to upload your NDA (PDF or DOCX)

Option 2: Custom Instructions

Persists across conversations. Limited to 1,500 chars.

  1. Go to chatgpt.com
  2. Click your profile picture (bottom left corner)
  3. Select Settings
  4. Click Personalization on the left menu
  5. Click Custom instructions
  6. Paste the prompt (use LITE version - FULL may be too long)
  7. Click Save

File Upload

ChatGPT supports PDF and DOCX uploads. Click the paperclip icon next to the message box to upload your NDA document.

Source: OpenAI Help Center - Custom Instructions

Using with Claude

Option 1: Direct in Conversation Recommended

Works with any prompt length. Interactive onboarding.

  1. Go to claude.ai
  2. Click New chat or start typing in the message box
  3. Copy the entire NDA Analyzer prompt and paste it into the message box
  4. Press Enter to send - the analyzer will ask for your preferences
  5. Reply with your choices or type "defaults" to use standard settings
  6. Click the paperclip icon to upload your NDA (PDF supported)

Option 2: Projects

Saves instructions for reuse. Free users: max 5 projects.

  1. Go to claude.ai
  2. Click Projects in the left sidebar
  3. Click Create project
  4. Give your project a name (e.g., "NDA Analyzer")
  5. Click the project instructions area and paste the prompt
  6. Optionally upload reference files to the project's knowledge base
  7. Click Start chat to begin analyzing NDAs

File Upload

Claude supports PDF uploads directly in chat. Click the paperclip icon next to the message box to upload your NDA document.

Source: Claude Help Center - Projects

Using with Google Gemini

Option 1: Direct in Conversation Recommended

Works with any prompt length. Interactive onboarding.

  1. Go to gemini.google.com
  2. Copy the entire NDA Analyzer prompt and paste it into the message box
  3. Press Enter to send - the analyzer will ask for your preferences
  4. Reply with your choices or type "defaults" to use standard settings
  5. Click the + icon (left of the message box) to add files
  6. Select Upload file and choose your NDA document

Option 2: Gems Gemini Advanced

Persistent instructions. Requires paid subscription.

  1. Go to gemini.google.com
  2. Open the sidebar by clicking the menu icon (three lines, top left)
  3. Click Gems in the sidebar menu
  4. Click New Gem
  5. Enter a name (e.g., "NDA Analyzer")
  6. Paste the prompt in the Instructions field
  7. Click Save
  8. Your Gem will appear in the sidebar - click it to start analyzing

File Upload

Gemini supports PDF, DOCX, and most file types. Click the + icon next to the message box, then select Upload file. Limit: 10 files per prompt, 100MB each.

Sources: Gemini Help - Gems | Gemini Help - File Upload

Troubleshooting

"Response got cut off"
Say: Continue from where you left off
Or use: OUTPUT_FORMAT=Executive for shorter output
"Not following the format"
Say: Follow the exact output format from the framework, including the Risk Assessment Matrix table
"Assuming clauses exist"
Say: If a clause is not found, mark it as "NOT PRESENT". Do not assume market-standard inclusion.

Tips

Auto-Analyze Just upload your NDA and the analyzer will give you a Risk Matrix immediately. No need to configure anything first.
Output Levels Default is matrix (quick overview). The output will show "Want more detail?" options for summary, full, extended, and complete.
LITE vs FULL Use LITE for quick 6-clause review. Use FULL for comprehensive 26-clause analysis.
